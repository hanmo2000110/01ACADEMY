# 청소년 AI 프로젝트 아카데미

영원교회의 중·고등학생 대상 약 12주 무료 교육 소개 사이트입니다.

## 수정 위치

- `dist/index.html`: 간결한 메인 소개와 탐색 링크
- `dist/curriculum.html`: 12주 과정과 작품 예시
- `dist/about.html`: 강사, 교육 방식, 운영 취지
- `dist/guide.html`: 준비물, FAQ, 공지, 문의 연락처
- `dist/content.js`: 작품 예시, 12주 수업 내용, FAQ
- `dist/styles.css`: 색상, 글꼴, 반응형 화면
- `dist/app.js`: 과정 필터, 주차 상세 안내

`node preview.mjs` 실행 후 http://127.0.0.1:4173 에서 확인합니다.

`main` 브랜치에 변경 사항을 푸시하면 GitHub Actions가 `dist` 폴더를 GitHub Pages에 자동 배포합니다.

## 운영 전 확인

- 상세 주소, 정원, 신청 양식, 정확한 종료 시간과 휴강 일정은 미확정입니다.
- 전화·문자 문의는 실제 연락처로 연결됩니다. 웹에서 신청 정보를 수집하거나 저장하지 않습니다.
- 학생 작품이나 학생 개인정보는 포함하지 않았습니다. 이미지는 설명용 생성 일러스트입니다.
- 도구별 무료 한도나 연령 정책을 확정된 사실로 게시하지 않았습니다. 실제 수업 전 공식 정보를 확인해야 합니다.
- 본인 전용으로 최초 게시합니다. 학부모·학생에게 배포할 때는 공개 범위를 별도로 변경해야 합니다.
- Google Fonts를 불러올 수 없는 환경에서는 시스템 sans-serif 글꼴로 표시합니다.

현재 수업 안내와 공지는 파일 수정으로 관리합니다. 학생 로그인·제출·관리자 편집 기능은 포함하지 않습니다.
